# tetr.rb
Tetris clone, in RUBY

Made with no Ruby-specific framework for games, everything is made with with a single JS canvas and [ruby.wasm](https://github.com/ruby/ruby.wasm).

image

# Features
- [x] Hard drop
- [x] ARR for better movement
- [x] Ghost piece
- [x] 7 Bag piece system
- [x] Auto restarting
- [x] SRS kicks
- [x] Lock delay
  - [ ] Keeps track of lowest point and cancels harder lock if below
- [x] Score
- [x] TSpins
  - [ ] scoring
- [x] Input list
